**Yes, Mastra fully supports it.** You can use cfo.ai’s remote MCP server (`https://api.cfo.ai/mcp`) from a Mastra-powered web app.

Mastra’s `MCPClient` speaks Streamable HTTP and has built-in OAuth support, which matches exactly what cfo.ai requires.

### How to connect it

1. Install the package:
```bash
npm install @mastra/mcp@latest
```

2. Basic client setup (for a static / shared token case):

```ts
import { MCPClient } from '@mastra/mcp'

export const cfoMcp = new MCPClient({
  id: 'cfo-client',
  servers: {
    cfoai: {
      url: new URL('https://api.cfo.ai/mcp'),
      requestInit: {
        headers: {
          Authorization: `Bearer ${process.env.CFO_ACCESS_TOKEN}`, // if you already have a token
        },
      },
    },
  },
})
```

3. For proper **user-delegated OAuth** (recommended for a web app):

Mastra provides `MCPOAuthClientProvider`. You configure it with an `authProvider` and handle the browser redirect yourself (the built-in `authenticate()` uses a local loopback callback, which is only suitable for CLI/local use).

```ts
import { MCPClient, MCPOAuthClientProvider } from '@mastra/mcp'

const oauthProvider = new MCPOAuthClientProvider({
  redirectUrl: 'https://your-web-app.com/oauth/callback', // your hosted callback
  clientMetadata: {
    redirect_uris: ['https://your-web-app.com/oauth/callback'],
    client_name: 'My CFO Web App',
    grant_types: ['authorization_code', 'refresh_token'],
    response_types: ['code'],
  },
  onRedirectToAuthorization: (url) => {
    // In a web app: redirect the user to this URL
    // or open it in a popup / new tab
    window.location.href = url.toString()
  },
  // You'll also need custom storage (not the default in-memory one)
  // so tokens are persisted per user
})

const mcpClient = new MCPClient({
  servers: {
    cfoai: {
      url: new URL('https://api.cfo.ai/mcp'),
      authProvider: oauthProvider,
    },
  },
})
```

### Using the tools in an agent

```ts
import { Agent } from '@mastra/core/agent'

const tools = await mcpClient.listTools()

export const cfoAgent = new Agent({
  id: 'cfo-agent',
  name: 'CFO Agent',
  instructions: 'Use the cfo.ai tools to inspect and edit financial models.',
  model: 'openai/gpt-4o', // or whatever you prefer
  tools,
})
```

For per-user tokens in a multi-tenant web app, create the `MCPClient` (or its toolsets) at request time rather than as a global singleton.

### Key points for a web app
- **OAuth is required** — cfo.ai does not support static API keys for the MCP endpoint.
- You must handle the OAuth redirect/callback in your web app and store tokens securely per user.
- All writes go through cfo.ai’s changelog and can be rolled back.
- After connecting, call `list_orgs` and pass the correct `org_id` if the user has multiple workspaces.

Official Mastra docs:
- [MCP connections](https://mastra.ai/docs/connections/mcp)
- [MCP authentication & authorization](https://mastra.ai/docs/guides/mcp-authentication-authorization)

This works the same way as connecting any other remote Streamable HTTP MCP server. Want a more complete example with the OAuth callback handler?
